# WavePos

WavePos는 `Park-os-admin`의 작업 방식과 폴더 구조를 참고해 만든 초기 프로젝트 골격입니다.

## 포함 내용
- `AGENTS.md`: 작업 응답, UI/UX 보호, Git 원칙
- `.agents/rules`: 공통 규칙, 데이터 동기화, React/Vite 구현 가이드
- `.agents/skills`: 반복 작업용 스킬 문서
- `docs/prd`: 도메인별 PRD 시작 문서
- `App.tsx` 중심의 Vite + React + TypeScript 실행 골격

## 시작 방법
1. `npm install`
2. `npm run dev`
3. 필요 기능을 `docs/prd/`에 먼저 정리한 뒤 구현합니다.
