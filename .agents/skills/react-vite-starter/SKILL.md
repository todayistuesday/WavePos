# React/Vite Starter 스킬

## 기본 흐름
1. 관련 PRD 확인
2. 타입 정의 추가
3. `components` 또는 `pages`에 화면 생성
4. 필요한 경우 `services`, `utils` 분리
5. 빌드 검증

## 주의
- 공통 레이아웃 수정은 요청 범위 안에서만 진행한다.
- 페이지 단위 기능이라면 공통 컴포넌트보다 해당 페이지 내부에서 먼저 해결한다.
