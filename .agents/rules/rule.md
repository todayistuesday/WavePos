# WavePos 공통 작업 규칙

## 역할
- 이 프로젝트는 `Rules`, `Skills`, `PRD`, `App`을 함께 운영하는 POS/Admin 시작 템플릿이다.
- 모든 구현은 먼저 문서와 범위를 확인한 뒤 최소 변경으로 진행한다.

## 언어 정책
- 응답, 문서, 주석은 기본적으로 한국어로 작성한다.
- 라이브러리명, 타입명, API 필드명은 영어를 허용한다.

## UI/UX 보호 원칙
- 사용자가 지정한 영역 외 UI/UX는 변경하지 않는다.
- 공통 컴포넌트 수정이 필요하면 영향 범위를 먼저 명확히 확인한다.
- 전체 리라이트보다 필요한 블록만 국소 수정한다.

## 구현 순서
1. `AGENTS.md` 확인
2. `.agents/rules/*` 확인
3. 관련 `docs/prd/*` 확인
4. 구현
5. 테스트 또는 빌드 검증

## 출력 원칙
- 답변은 간결하게 작성한다.
- 변경 요약과 테스트 여부를 반드시 포함한다.
- 전체 파일을 그대로 출력하지 않는다.
