# 데이터 동기화 규칙

## 목적
- 화면에서 보이는 값, 초기 데이터, 저장 구조가 서로 어긋나지 않도록 관리한다.

## 원칙
- 신규 도메인 추가 시 타입 정의, 초기 데이터, 화면 표시 항목을 함께 업데이트한다.
- 임시 저장은 보조 수단으로만 사용하고, 기준 데이터 구조는 코드와 문서에 남긴다.
- 저장 구조가 바뀌면 버전 키를 올려 호환성 기준을 명확히 한다.

## 체크리스트
- `types.ts`에 필요한 타입이 반영됐는가
- `constants.tsx` 또는 도메인 초기값이 반영됐는가
- 관련 PRD 문서가 같이 갱신됐는가
- 화면의 라벨과 저장 필드가 일치하는가
