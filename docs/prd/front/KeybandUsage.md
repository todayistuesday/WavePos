# 키밴드 사용 (Keyband Usage) PRD

## 1. 목적
스캐너로 입력받거나 사용자가 직접 입력한 키밴드 정보(키밴드 번호, 예약 번호, 연락처 등)를 바탕으로 사용 가능한 티켓을 조회하고, 티켓의 사용 처리(부분 사용, 전체 사용, 사용 취소/복구)를 수행할 수 있는 기능을 제공한다.

## 2. 대상 사용자
- POS 관리자 및 매장 직원

## 3. 핵심 화면
- **키밴드 사용 팝업 (모달)**
  - 검색 영역: 검색어 입력창, 조회 및 초기화 버튼
  - 결과 영역: 키밴드별 사용 가능한 티켓 목록, 티켓 상세 정보(상품명, 권종, 이용 시간, 수량 선택, 처리 버튼)
  - 접근성: `role="dialog"`, `aria-modal="true"` 등 지원, Esc 키 및 배경(Backdrop) 클릭 시 닫기 지원

## 4. 입력/출력 데이터

### 4.1. 검색 조건 (입력)
- **검색어 (Query)**: 키밴드 번호, 예약 번호, 휴대폰 번호 전체
- **동작 방식**: 
  - 영문/한글 등 일반 문자열이 포함된 경우: 부분 일치 검색 (상품명, 권종, 이용 시간, 키밴드 번호, 예약 번호)
  - 숫자로만 이루어진 경우 (`queryDigits`): 정확한 일치 검색 (키밴드 번호, 휴대폰 번호)

### 4.2. 조회 결과 (출력)
- **키밴드 기본 정보**: 키밴드 번호 (예: `bandNo`)
- **티켓 목록 (`items`)**:
  - 상품명 (`productName`)
  - 권종 (`ticketName`)
  - 이용 시간 (`session`)
  - 수량 (`quantity`): 남은 수량에 맞춰 선택 가능한 콤보박스로 노출
  - 처리 상태: "사용 처리", "부분 사용", "사용 완료" 액션 버튼

## 5. 예외 처리
- **검색어 미입력**: "조회할 키밴드 정보를 입력한 뒤 조회 버튼을 눌러주세요." 문구 노출
- **검색 결과 없음**: "일치하는 키밴드 정보가 없습니다." 문구 노출
- **사용 수량 초과 방어**: 선택 가능한 수량이 남은 수량(`remainingQuantity`)을 초과하지 않도록 제한
- **사용 취소/복구 (수정일: 2026-06-22)**: "부분 사용" 상태에서는 사용 복구를 할 수 없으며, "사용 완료" 상태일 때 버튼을 클릭하여 전체 수량에 대한 복구가 가능하다. `window.confirm("사용 완료된 항목을 복구하시겠습니까?")` 컨펌 후 확인 시 사용 상태가 완전히 초기화된다.
- **사용 처리 컨펌 정책 (수정일: 2026-06-22)**:
  - "사용 처리", "부분 사용", "사용 완료"로 이어지는 사용 차감 액션에는 별도 컨펌을 두지 않는다.
  - 본 화면은 POS 현장에서 반복적으로 수행되는 빠른 처리 흐름을 전제로 하므로, 매 클릭마다 확인 단계를 추가하면 사용 속도와 응대 흐름이 크게 저하될 수 있다.
  - 대신 되돌리기 성격이 강한 "복구" 액션은 이미 처리된 상태를 초기화하는 동작이므로, 실수 방지를 위해 컨펌을 유지한다.
  - 즉, 사용 처리 단계는 즉시성 중심, 복구 단계는 신중성 중심으로 UX 정책을 구분 적용한다.

## 6. 구현 범위 및 기술 정의

### 6.1. 검색 매칭 알고리즘
- `normalizedQuery`: 공백을 제거하고 소문자로 변환된 검색어
- `normalizedDigits`: 정규식 `/\D/g`를 사용하여 숫자만 추출한 검색어
- **텍스트 매칭 (`textMatched`)**: 상품명, 권종, 이용 시간, 밴드 번호, 예약 번호의 부분 일치
- **전화번호 매칭 (`phoneMatched`)**: 입력된 숫자가 밴드 번호나 전화번호와 완벽히 일치할 때 적용

### 6.2. 티켓 수량 및 상태 관리 로직
- `usedTicketQuantities`: 각 티켓(`ticketId`)별 누적 사용된 수량을 관리 (`Record<string, number>`)
- `selectedUsageQuantities`: 드롭다운 컴포넌트(Select)에서 현재 사용하기 위해 선택한 수량을 관리 (`Record<string, number>`)
- **상태 판별**:
  - `isFullyUsed`: `usedQuantity >= totalQuantity` (전부 사용됨 -> 콤보박스 disabled, 버튼 "사용 완료")
  - `isPartiallyUsed`: `usedQuantity > 0 && usedQuantity < totalQuantity` (일부 사용됨 -> 버튼 "부분 사용")
  - `remainingQuantity`: `totalQuantity - usedQuantity` (남은 수량에 맞춰 드롭다운 Option 목록 동적 생성)
- **수량 차감 처리 (`handleUseTicket`)**:
  - 남은 수량 범위 내에서 선택된 수량만큼 `usedTicketQuantities` 누적합 계산
  - 사용 후, 다음 선택 가능한 `selectedUsageQuantities` 값을 남은 수량에 맞춰 자동 갱신

### 6.3. UX/UI 디테일
- 다중 수량 항목에 대한 안내 문구 제공: "※ 수량이 2개 이상인 항목은 남은 수량 안에서 필요한 개수만 선택해 사용 처리할 수 있습니다."
- 팝업 종료 핸들링: 키보드 `Escape` 이벤트 리스너를 통한 종료 및 `backdrop` 클릭 시 종료 로직 포함
